MY FOREX JOURNAL - ANDROID PWA PROJECT

This is a Progressive Web App project, not a prebuilt APK.
To install as a PWA:
1. Host these files on an HTTPS website.
2. Open the website in Chrome on Android.
3. Open Chrome menu (three dots) > Install app / Add to Home screen.
4. Open it once online so the service worker caches the app; it can then work offline.

For a standalone Android APK:
1. First publish this PWA on HTTPS.
2. Open https://www.pwabuilder.com/ in Chrome and enter the hosted URL.
3. Choose Package for stores > Android > Generate Package.
4. For a personal test APK, choose the Other Android option if offered and follow signing instructions.
5. Keep your signing key safe. A Google Play release has additional requirements.

Data is stored in browser localStorage on this device/origin. Do not clear site data.
Use Export CSV or Backup JSON regularly. Restore JSON can replace current records.
This app is a journal only; it does not connect to a broker or execute trades.
